# 常见失败与反例（Anti-Patterns）

> 来源：GeoGebra 引擎真机实测 + 验证器回归用例。生成或调试中遇到报错、图形没出来、按钮没反应时，先查这份清单。
> 配套：`scripts/validate_commands.py`（L1）/ `scripts/validate_types.py`（L2）会静态拦截其中一部分；带 ⚙️ 的条目只有**真机执行**（`tools/ggb-export` 或导入 GeoGebra）才能暴露。

## A. 引擎 / 语法坑（真机实测）

| # | 症状 | 根因 | 处置 |
|---|---|---|---|
| A1 ⚙️ | 两点间 `Line(...)` 报错或结果不对 | 小写名 + 坐标被解析为**向量**：`pt1 = (0,0)` 创建的是向量 | 点的名字用大写（`P1`）或显式 `Point(...)`；L1 会提醒 |
| A2 ⚙️ | 对象引用不到；代数区出现 `sec_{1}` | 与内置函数同名（`sec`/`tan`/`sin`/`ln`…）被引擎**自动改名** | 避免用内置函数名作对象名；L1 会提醒 |
| A3 ⚙️ | `Line(A, B)`「成功」但图形区什么都没有 | **退化初值静默不创建**：滑块范围含 0 且初值为 0 → A、B 重合 | 构造前先 `SetValue(h, 0.5)` 设非零初值；L1 有启发式预检 |
| A4 ⚙️ | `SetValue` / `SetColor` / `ShowLabel` 返回 `false`，误判为失败 | **脚本命令返回值不可信**，效果真实生效 | 用 getter 核验（`getValue` / `getColor` / `getLabelVisible`）；导出器已内置 |
| A5 ⚙️ | `Button("标题","脚本")` 静默失败 | 二参 Button 经命令注入不受支持 | `Button("标题")` 创建 + `ggb_patch.py` 注入 `<ggbscript>` |
| A6 | `a = 1` 期望出现滑块 | 简化写法不创建滑块 | 必须写 `Slider(min, max, step)` |
| A7 | `Text("...\n...")` 不换行 | `Text()` 不支持 `\n` | 用 LaTeX `\\` 换行（多行对齐用 `\begin{aligned}`） |
| A8 ⚙️ | 定义 `e = 5` 后内置自然常数失效；`pi = 3` 变成方程对象 | 与内置**常量名**重名 | 用 `eVal` / `piVal` 等别名 |
| A9 | 多语句脚本只执行第一条 / 报错 | GGBScript 语句分隔符 | 用**换行**分隔（分号不行） |
| A10 ⚙️ | `Element(hitM, 1)` 报错，即便区间内只有一个交点 | `Intersect(<函数>, <函数>, a, b)` 在**唯一交点**时返回**单个 Point**（不是 List）；`Element(Point, n)` 求值即失败，`If(IsDefined(Element(point,1)), …)` 也救不了 | 需要"解 f(x)=c"用 `Root(f − c, a, b)` 取**数值**（真机实测，T1 拉格朗日中值定理） |
| A11 ⚙️ | `Eigenvalues(...)` / `Eigenvectors(...)` 执行失败，即使用字面量矩阵 | 二者为 **CAS 专属**，本技能导出引擎（无头 classic app）不支持；索引里有、L2 不报错，只有真机才暴露 | 2×2 手算：`tr=a11+a22`，`det=a11*a22−a12*a21`，`λ=(tr±√(tr²−4·det))/2`；特征向量方向 `(a12, λ−a11)`（a12≠0 时，否则 `(λ−a22, a21)`）；用 `If(det>=0, sqrt(disc), 0)` 防复数。L1 现已静态提醒（真机实测，T4 特征向量） |
| A12 ⚙️ | 图形区冒出莫名其妙的曲面 / 直线 | `Derivative(f, x)` 等中间函数**本身可绘制**，会作为曲面/曲线自动显示 | `SetVisibleInView(fn, -1, false)`（3D）/ `SetVisibleInView(fn, 1, false)`（2D）隐藏（真机实测，T2 方向导数） |
| A13 ⚙️ | 导出报告 `ok`、对象数却没变，怀疑 `Sequence`/`Zip` 列表为空 | 用 `Sequence`/`Zip` 造出的**对象列表**（线段、点）在 .ggb 里只存**定义**（`<command>`），不逐个列为元素；`objectsBefore/After` 也数不到——**空列表与满列表长得一样** | 用 `Length(列表)` 核验元素个数，或看预览图 / 导入 GeoGebra 确认（真机实测，T5 置信区间） |
| A14 ⚙️ | 变上限积分函数 Φ(x)=∫ₐˣf 画不出来 / 处处 NaN | `F(x)=Integral(f, x)`（反导数）作函数求值**返回 NaN**；`Acc(x)=Integral(f, a, x)`（变限）**根本不创建** | 用**黎曼和**近似：`Phi(x) = Sum(f(a + (x - a) * i / n) * (x - a) / n, i, 1, n)`，n 取 200（真机实测，T7 变上限积分）。**注**：定积分 `Integral(f, a, b)`（a,b 为数值）**可用**——只有"作函数/变限"形式失效（真机实测，T112） |
| A15 ⚙️ | `SolveODE(f, 点)` 的解曲线不显示、也求不出值 | 二参 `SolveODE(<f>, <Point>)` 返回**不可求值的 function**（NaN、不绘制）；数值式才返回可绘制的 **locus** | 用 `SolveODE(f, x0, y0, xEnd, step)`（可为负方向）；曲线族用 `Sequence(SolveODE(f, 0, 0.2*i, 6, 0.05), i, 1, 7)`（真机实测，T11 Logistic） |
| A16 ⚙️ | `Segment(projP, P)` 失败；`Point(<向量>)` 失败 | `(0,0) + 向量` 在此引擎被解析为**向量**（非点）；`Point(向量)` 不可转 | 求垂足用 `ClosestPoint(<直线>, <点>)`（返回**点**）；来源点+向量得点请用 `ClosestPoint` 或直接构造坐标点（真机实测，T8 正交投影） |
| A17 ⚙️ | 面积模型里冒出一堆字母标签（`f`、`g9`、`t9`…） | `Polygon(...)` 会**自动创建 4 条边线段**，且这些边作为新对象**默认显示标签**，又无法按名引用去隐藏 | 无法直接隐藏；面积模型尽量**减少多边形个数**，或接受这些杂标签（真机实测，T9 贝叶斯面积模型） |
| A18 ⚙️ | 为绘图而定义的**辅助函数**也出现在图上（重复曲线/多余曲面） | 用户定义的函数只要存在就会被**自动绘制** | `SetVisibleInView(fn, 1, false)`（2D）/ `(fn, -1, false)`（3D）隐藏——与 A12 同源，泛指一切"为计算而定义、不为展示"的函数（真机实测，T7） |
| A19 ⚙️ | `BinomialDist(n,p,k)` / `Poisson(λ,k)` 执行失败；`Normal(μ,σ,x)` 的结果不是密度 | 分布命令的"取某点概率"形式在本引擎不可用；`Normal(μ,σ,x)` 实际返回**累积概率** | 密度用 4 参 `Normal(μ,σ,x,false)`；离散 pmf **显式算**：`BinomialCoefficient(n,k)*p^k*(1−p)^(n−k)`、`λ^k*exp(−λ)/k!`（真机实测，T22/T24） |
| A20 ⚙️ | `(x,y)^2` 得到的是**标量点积**，不是复平方 | 坐标对 `(x,y)` 是向量/点，`^2` 对其作内积；点也一样 | 复数必须用**字面量** `a + b*i`（如 `(1+0.5i)^2` → 点）；z² 映射用显式坐标公式 `(x²−y², 2xy)`（真机实测，T20） |
| A21 ⚙️ | `BarChart(起点, 终点, 高度列表)` 返回一个**数值**而非条形图 | 该 3 参形式在本引擎行为异常 | 柱状/离散分布改用 `Sequence(Segment((k,0),(k,p(k))), k, …)`（列表会渲染），对比曲线用 `Polyline(点列表)`（真机实测，T22） |
| A22 ⚙️ | `Histogram(边界, 数据, …)` / `Histogram(边界, 高度)` 返回**数值**，不画直方图 | 分布可视化命令（`Histogram` 同 `BarChart`）在本引擎不产出图形 | 直方图/柱状一律**手工搭**：`Sequence(Segment(...))` 或 `Sequence(Polygon(...))`（真机实测） |
| A23 ⚙️ | `Iteration(…)` / `IterationList(…)` 执行失败（各写法均试过） | 迭代命令在本引擎不可用 | 需要迭代序列（牛顿法、Euler 法）时**手写前几步**：`x1 = x0 − f(x0)/f′(x0)`、`x2 = x1 − f(x1)/f′(x1)` …（真机实测，T33） |
| A24 ⚙️ | `cnt(k) = CountIf(边界(k) ≤ mm < 边界(k+1), mm, 列表)` 失败 | `CountIf` 的条件里含**参数相关的边界/用户函数**（两个绑定变量 `k`、`mm` 嵌套）时失败；单纯字面边界的 `CountIf` 正常 | 边界尽量**内联**为简单表达式；直方图分箱若卡住，改用 `Sequence`+`Zip` 或手工搭（真机实测） |
| A25 ⚙️ | 字面量点列表 `{(x,y), …}` 定义后，图上的数据点**看不见** | 该引擎把**字面量列表**创建为**隐藏**（`show object="false"`）；`Sequence` 生成的列表、`Append` 的结果则可见 | 对字面量点列表加 `SetVisibleInView(列表, 1, true)`（或改用 `Sequence`/`Append` 生成）（真机实测，T40/T34/T43） |
| A26 ⚙️ | `Rank(<矩阵>)` 执行失败 | 该命令在本引擎不可用 | 判断线性相关用 `Determinant`（2×2：det=0 ⟺ 共线）；更高维可参考 `ReducedRowEchelonForm`（真机实测） |
| A27 ⚙️ | `ln = a*x + b*y = c`（把**方程本身**当对象）执行失败 | 经命令注入时，**方程形式的对象定义**（含 `=`）不受支持 | 直线用 `Line(点, 点)` / `Line(点, 向量)`；由方程 `a*x + b*y − c = 0` 可用 `ImplicitCurve(a*x + b*y - c)`（真机实测，probeL） |
| A28 ⚙️ | 纯 3D 曲面/几何体场景（`Surface(f,2π)`、`Cylinder`、`Cone`…）导出预览仍是 2D、看不到 3D | 3D 元素实际类型是 `surfacecartesian3d` / `quadriclimited` 等**带后缀名**，旧版 3D-检测正则只写 `surface` → 漏判、不切 3D 视图 | **已修**：导出器正则改为匹配**任何含 `3d`/`quadric`/`surface` 的类型名**（覆盖 `surfacecartesian3d`、`quadriclimited` 等）（真机实测，T70/T74） |
| A29 ⚙️ | `SetCaption(Vec, "T")` 设了标题，图形区仍不显示标签 | `SetCaption` 只把对象 `labelMode` 置为 caption（`val=3`），但该对象 `show label` 仍为 `false` | 追加 `ShowLabel(对象, true)` 才会显示 caption（真机实测，T107） |
| A30 ⚙️ | 嵌套求和 `Sum(Sum(expr, rr, 1, 60), tt, 1, 90)` 执行失败（各项单独都合法） | 本引擎对**嵌套 `Sum`**（内层不含外层变量）支持不佳 | 把双重求和**可分离化**：内层单独定义 `inner = Sum(...)`，外层用析出因子替代（如 `inner * 2*pi`），或改用单层 `Sum`（真机实测，T119） |
| A31 ⚙️ | `OsculatingCircle(<点>, <3D 曲线>)` 执行失败（二维曲线上可用，见 T30 曲率圆） | 密切圆命令**不支持空间曲线** | 3D 曲线的曲率/挠率改用**解析式** + `Vector(...)` 画 T、N 箭头 + 动态文本给 κ、τ（真机实测，T124） |
| A32 ⚙️ | `m = max(a, b)` / `min(...)` 表达式失败（各项均合法，L1 也不报"未知命令"） | GeoGebra 的 `Max`/`Min` 是**首字母大写的命令**，小写 `max()`/`min()` 不被识别 | 改用 `Max(a, b)` / `Min(a, b)`；L1 已加静态提醒 `lowercase-command`（真机实测，T135） |

## B. 验证行为坑

| # | 症状 | 根因 | 处置 |
|---|---|---|---|
| B1 | L1 对 `Polygon(Sequence(…, k, …))` 报「单字母变量未定义」 | 嵌套迭代变量的历史误报 | v1.4.1 已修复（迭代命令内豁免）；若仍出现，按 `command-validation.md` 人工复核 |
| B2 | 静态验证全绿，导入引擎仍失败 | 静态验证**覆盖不到**：GGBScript 脚本、自定义工具、复杂 `Locus`、3D 交线、`Zip` 嵌套等 | 静态只是下限；交付前用 `tools/ggb-export` 实跑（或 ggbgen / 本地导入确认） |
| B3 | 换机器后验证器报找不到索引 | 索引按脚本位置自动定位（相对结构） | 保持技能目录结构完整；或参考脚本内候选路径改用环境变量/传参 |
| B4 | L1 报 `Zip(... mm ...)` 变量「使用前未定义」、L2 报 `Zip 参数类型不匹配`（(Line, Unknown, List, …)） | 迭代命令**绑定的循环变量**被误当未定义变量；Zip「变量位/列表位交替」的签名不适用通用类型匹配 | **v1.5.0 已修复**：L1 提取 Zip/Sequence/… 的绑定变量并豁免（含多字符名，如 `mm`）；L2 对 Zip 只做结构检查（参数个数为奇数） |
| B5 | L1 报 `arctan` / `arcsin` / `arccos` … 「使用前未定义」 | 反三角**长拼写别名**不在内置函数表 | **v1.5.0 已修复**（补入 `arcsin/arccos/arctan/arccot/arcsec/arccsc`） |
| B6 | L1 把首字母大写的**用户函数**（`FC(x) = …` 的定义行，或 `y = FC(2)` 的调用行）当成「未知命令」 | 命令名识别只认首字母大写；未把脚本内已定义的函数名当成"已知" | **v1.5.1 已修复**（命令名若出现在脚本 `defined_vars` 中，或形如 `Name(...) = …` 定义行，跳过未知命令检查） |
| B7 | L1 报 `Curve(t, …, t, …)` 的参数变量 `t` 「使用前未定义」 | `Curve` / `Function` 的参数变量未被当作绑定变量 | **v1.5.1 已修复**（`Curve`/`Function` 列入迭代命令豁免，参数变量视为已定义） |
| B8 | L2 报 `Dot(<点>, <点>)` 参数类型不匹配；报 `SetLineStyle(<函数>, n)` 需要 `Line` | 点可作位置向量参与 `Dot`；样式类命令第一参可为任意可绘制对象，而索引签名过窄 | **v1.5.1 已修复**（点纳入 Vector 的可接受集；`SetLineStyle/SetLineThickness/…` 跳过类型检查） |
| B9 | L1 报 `gg(k) = …` 里的形参 `k` 「使用前未定义」 | 函数定义的形参未被当作"本行已定义" | **v1.5.2 已修复**（提取 `Name(参数…) = …` 的形参并豁免） |
| B10 | L1 报 `BinomialCoefficient` / `nCr` 「使用前未定义」 | 组合数函数不在内置函数表（但真机可用） | **v1.5.2 已修复**（补入 `BinomialCoefficient` / `nCr` / `nPr`） |
| B11 | 导出偶发 `EBUSY: resource busy or locked … DevToolsActivePort` | 临时浏览器 profile 被占用（前次进程残留 / 杀软扫描），非指令问题 | 直接**重试一次**即可（真机实测，偶发） |
| B12 | 无头预览里**希腊字母**（ζ、ω 等）显示为空/缺字形，但 `.ggb` 文本本身正确 | 无头 Chrome 缺对应字体字形（中文正常、希腊字母缺） | `.ggb` 本体无碍（教师本地 GeoGebra 字体齐全）；预览只作功能核对，**不必因缺字重导**（真机实测，T82） |
| B13 | L1 报 `Surface(u, v, u^2−v^2, u, −1, 1, v, −1, 1)` 的参数变量 `u`/`v` 「使用前未定义」 | `Surface` 的参数变量未被当作绑定变量（`Curve`/`Function` 已豁免，`Surface` 漏了） | **v1.5.14 已修复**（`Surface` 列入迭代命令豁免，裸标识符参数视为已定义） |
| B14 | 3D 场景中 `Text(..., (<x>,<y>,<z>), true, true)` 的文字在无头预览里**不显示** | 无头 3D 视图（`getPNGBase64`）不渲染 `text` 对象；文字位置其实已写入 `.ggb` 的 `<startPoint>`，本体正确 | 预览中 3D 文字缺失**不等于**功能错误；用 `insp.py`/XML 查 `<startPoint>` 确认已创建（真机实测，T107） |
| B15 | 3D 场景里 `ZoomIn(minX,minY,minZ,maxX,maxY,maxZ)` 对**导出预览**无效，视角不变 | 导出器检测到三维对象后 `setPerspective("T3")` 重置视图，覆盖此前 `ZoomIn` | 3D 预览取景由导出器决定；不必再用 `ZoomIn` 调 3D 取景（真机实测，T107） |

## C. 教学设计反例（评审视角）

- ❌ **一个 .ggb 塞多个概念**（导数 + 泰勒 + 积分）→ 拆成多个小而精的演示；
- ❌ **滑块拖动后画面几乎不变** → 范围 / 函数 / 区间没让关键现象（极值、拐点、逼近过程）落在可视范围内；
- ❌ **默认状态平庸或空白** → 目标：打开即「顿悟时刻」，默认参数直接呈现核心现象；
- ❌ **核心控件超过 5 个** → 学生不知所措；探索项折叠或默认隐藏；
- ❌ **数值文本与几何脱钩**（硬编码数字）→ 用 `Slope(...)` / `Area(...)` 等从几何对象计算；
- ❌ **把函数写死在指令里** → 优先 `InputBox(f)` 关联，教师可现场改函数。
- ❌ **反复截图检查文字遮挡/位置、为版面微调多轮重新导出** → 不必要且拖慢交付：教师打开后可自行拖动对象、缩放窗口；版面只守数量预算（控件 ≤5、动态文本 ≤5、能不显示的不显示），功能性问题（图形没出来、数值不对）才重导。
