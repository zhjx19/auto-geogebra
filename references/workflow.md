# GeoGebra 教师创作工作流

核心问题不是“学生要看到什么变化”，而是：

> 普通老师想让学生看到什么变化？

推荐流程：

1. 教师描述教学主题和创作意图。
2. 明确老师想让学生观察的变化。
3. 设计交互变量：参数、点、增量、样本量、分割数等。
4. 把变量转化为滚动条、可拖动点、按钮或复选框。
5. 按参数 → 数学对象 → 辅助对象 → 动态文本 → 样式的顺序拆解。
6. 生成 GeoGebra 指令代码。
7. 真机导出检查可运行性（`tools/ggb-export`，退出码 0 即通过；预览图按需生成）。
8. 根据教学效果迭代——**只迭代数学内容**（范围、函数、默认值、文本措辞）；不做文字遮挡/位置的截图巡检，不为此重新导出（教师可自行拖动对象、缩放窗口），版面守「控件 ≤5、动态文本 ≤5、能不显示的不显示」即可。
