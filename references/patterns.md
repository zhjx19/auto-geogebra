# GeoGebra 教学创作模式库

本文件是从用户 `math-ggb` 案例库与高校数学公共课教学经验中凝练出的创作经验。它不是案例索引，也不要求技能包绑定这些案例；其目的只是提升面向普通教师开发新 GeoGebra 作品时的设计质量。

## 1. 总原则：从“想让学生看到什么变化”开始

教师创作 GeoGebra 动态演示时，优先把教学意图翻译成“可观察的变化”：

- 几何位置变化：点移动、线旋转、面移动、交点/交线变化。
- 逼近过程变化：割线趋近切线、矩形和趋近面积、正多边形趋近圆、泰勒多项式趋近函数。
- 参数影响变化：函数参数、矩阵元素、分布参数、样本量、角度、半径。
- 结构保持或改变：线性变换中的共线、面积伸缩、特征方向不变。
- 随机稳定性变化：样本量增加后频率、均值、直方图或抽样分布趋于稳定。

然后再设计交互变量、对象构造和指令。

## 2. 交互变量设计经验

### 2.1 滑块优先承载“教师希望学生调节的量”

常见滑块类型：

| 类型 | 典型变量 | 教学用途 |
|---|---|---|
| 位置变量 | `a`, `x0`, `t` | 点沿曲线移动、切点变化、路径参数变化 |
| 增量变量 | `h`, `Δx`, `dx` | 割线逼近切线、微分近似、局部线性化 |
| 分割变量 | `n` | 黎曼和、正多边形逼近圆、数列项数、级数部分和 |
| 形状参数 | `a,b,c,r,θ` | 函数族、圆锥曲线、曲面、旋转体 |
| 矩阵参数 | `a11,a12,a21,a22` 或角度/伸缩参数 | 线性变换、特征值、行列式 |
| 概率参数 | `p, λ, μ, σ, n` | 分布曲线、样本量、置信水平、抽样模拟 |

经验：每个滑块必须有“教学含义”，不要为了炫技暴露太多参数。普通教师作品通常 1~4 个核心交互变量最清晰。

### 2.2 可拖动点适合承载“几何直觉”

可拖动点比滑块更适合：

- 在曲线上取点；
- 平面区域中移动点；
- 改变向量端点；
- 观察局部变化或方向变化。

若教师描述“让学生拖动一个点看……”，优先设计点对象；若描述“调节参数/数量/角度”，优先设计滑块。

## 3. 对象构造顺序经验

推荐生成顺序：

1. 参数/滑块/可拖动点；
2. 基础函数、曲线、矩阵、分布或曲面；
3. 由基础对象派生的点、线、面、区域；
4. 辅助对象：投影线、垂线、交点、线段、向量；
5. 动态文本：当前参数值、公式、观察提示；
6. 样式：颜色、线型、显示/隐藏、图层；
7. 验证：拖动关键变量，检查核心变化是否显著。

经验：GeoGebra 对象依赖顺序很重要。先定义稳定的基础对象，再定义依赖对象，最后美化与说明。

## 4. 常见创作模式

### 4.1 逼近型模式

适用：导数定义、黎曼积分、数列极限、级数部分和、泰勒公式、正多边形逼近圆。

设计套路：

- 交互变量：逼近程度，如 `h`、`n`、阶数 `k`。
- 固定对象：目标对象，如切线、真实面积、极限值、原函数。
- 变化对象：逼近对象，如割线、矩形和、多项式、部分和。
- 动态文本：显示“当前逼近值”和“目标值/误差”。

常用命令：`Sequence`, `Zip`, `Segment`, `Polygon`, `RectangleSum`, `UpperSum`, `LowerSum`, `Integral`, `Tangent`, `TaylorPolynomial`, `Limit`。

### 4.2 局部线性化模式

适用：导数、微分、偏导数、方向导数、切平面、全微分。

设计套路：

- 交互变量：基点坐标、增量、方向角。
- 基础对象：函数图像或曲面。
- 派生对象：切线/切平面、割线/割平面、投影线、增量线段。
- 观察重点：局部范围越小，线性近似越好。

常用命令：`Tangent`, `Derivative`, `Point`, `Line`, `Plane`, `Segment`, `Intersect`, `Surface`, `Curve`。

### 4.3 区域与面积/体积模式

适用：定积分元素法、旋转体体积、曲线围成区域、二重积分区域、截面法。

设计套路：

- 交互变量：区间端点、微元位置、分割数、旋转角或参数。
- 基础对象：边界曲线/曲面。
- 变化对象：典型微元、矩形条、截面、旋转片。
- 观察重点：从“一个典型微元”到“累积整体”。

常用命令：`Integral`, `IntegralBetween`, `RectangleSum`, `Polygon`, `Segment`, `Surface`, `Curve`, `Cylinder`。

### 4.4 参数曲线/曲面模式

适用：极坐标曲线、空间曲线、旋转曲面、柱面、球面与柱面交线、多元函数图像。

设计套路：

- 交互变量：路径参数、曲面参数范围、形状参数。
- 基础对象：参数曲线或参数曲面。
- 辅助对象：当前参数点、投影线、切向量、交线。
- 观察重点：参数变化如何生成几何对象。

常用命令：`Curve`, `Surface`, `Point`, `Segment`, `IntersectPath`, `Plane`, `Sphere`, `Cylinder`。

### 4.5 变换型模式

适用：线性代数中的线性变换、旋转、反射、缩放、行列式、特征向量。

设计套路：

- 交互变量：矩阵元素、旋转角、伸缩比例、向量方向。
- 基础对象：原向量、网格、单位正方形或图形。
- 变化对象：变换后的向量、网格、面积图形。
- 观察重点：哪些结构保持，哪些结构改变。

常用命令：`Vector`, `ApplyMatrix`, `Translate`, `Rotate`, `Reflect`, `Dilate`, `Polygon`, `Segment`, `Angle`。

### 4.6 随机模拟与统计稳定型模式

适用：二项分布、泊松分布、正态近似、大数定律、中心极限定理、最小二乘。

设计套路：

- 交互变量：样本量 `n`、重复次数 `m`、分布参数 `p/λ/μ/σ`。
- 基础对象：随机样本或理论分布。
- 变化对象：频率图、直方图、均值轨迹、拟合线。
- 观察重点：随机波动与长期稳定、经验分布与理论分布的接近。

常用命令：`Sequence`, `RandomDiscrete`, `Histogram`, `BarChart`, `BinomialDist`, `Poisson`, `FitLine`, `Mean`, `SD`。

### 4.7 统计推断与覆盖率模拟模式

适用：样本均值抽样分布、**置信区间覆盖率**、假设检验的拒绝域与 p 值、一类/二类错误。

设计套路：

- 交互变量：样本量 `n`、重复次数 `m`、置信水平、真值 `mu0`、分布参数。
- 基础对象：一串随机样本（`Sequence(RandomNormal(...), …)`）。
- 变化对象：每条样本一个置信区间（横条），一条竖线标出真值。
- 观察重点：单条区间时好时坏（随机性），多条一起看覆盖率稳定在 1−α 附近（大数定律 + 频率稳定）。

常用命令：`Sequence`, `RandomNormal`, `Mean`, `Element`, `Zip`, `Sum`, `CountIf`, `Segment`, `ZoomIn`。

要点（真机实测，T5）：

- 竖排 m 条区间时用 `k * (10 / m)` 作纵坐标压住总高度，再用 `ZoomIn(-3, -0.5, 3, 10.5)` 定视图；
- 覆盖率 = `Sum(Zip(If(abs(mm - mu0) <= moe, 1, 0), mm, means)) / m`；
- 重抽样按钮用 `tick` 变量驱动重算（见 interaction-patterns.md 第 8 节）；
- `Sequence`/`Zip` 造的区间列表在 .ggb 里只存定义，用 `Length()` 核验而非数对象。

### 4.8 方向场与积分曲线模式（常微分方程）

适用：一阶微分方程方向场、解曲线族、Logistic 方程、平衡点与稳定性、相线图。

设计套路：

- 交互变量：可拖动的初始点、方程参数。
- 基础对象：方向场 `SlopeField(f(x,y), n)`。
- 变化对象：过初始点的积分曲线 `SolveODE(f, P0)`。
- 观察重点：方向场决定"水流方向"，积分曲线顺着它走；拖动起点看到不同解曲线。

常用命令：`SlopeField`, `SolveODE`, `Curve`, `Point`, `Segment`。

要点（真机实测，T6/T11）：`SlopeField(f, n)` 生成方向场（导出为 `locus` 元素）；解曲线用 **数值式** `SolveODE(f, x0, y0, xEnd, step)`（返回可绘制的 `locus`；步长/区间的终点可为负以向左积分）；**二参** `SolveODE(f, 点)` 返回的是**不可求值**的 `function`（NaN、不绘制）——见 [anti-patterns.md](anti-patterns.md) A15。曲线族：`Sequence(SolveODE(f, 0, 0.2*i, 6, 0.05), i, 1, 7)`。

### 4.9 手动特征分解模式（2×2，规避 CAS 限制）

适用：特征值/特征向量、不变方向、对角化、二次型主轴。

设计套路：

- 因 `Eigenvalues`/`Eigenvectors` 是 CAS 专属、导出引擎（无头 classic app）**执行失败**（真机实测），2×2 一律手算：
  - `tr = a11 + a22`，`det = a11*a22 − a12*a21`，`disc = tr^2 − 4*det`；
  - `root = If(disc >= 0, sqrt(disc), 0)`（防复数），`λ1 = (tr + root)/2`，`λ2 = (tr − root)/2`；
  - 特征向量方向：`(a12, λ − a11)`（a12 ≠ 0 时），否则 `(λ − a22, a21)`；过原点画线即不变方向。
- 交互变量：矩阵元素（4 个滑块）、一个角度滑块给出试探方向。
- 观察重点：当方向向量与特征方向共线时（叉积 ≈ 0），像与原像共线——方向不变。

常用命令：`Slider`, `Line`, `ApplyMatrix`, `Vector`, `If`, `sqrt`。（不依赖 `Eigenvectors`。）

### 4.10 变上限积分与累积函数模式

适用：变上限积分 Φ(x)=∫ₐˣf、定积分的"累积过程"、原函数的生成。

设计套路：

- 交互变量：下限 `a`、上限 `x`、被积函数 `f`。
- 基础对象：`f` 的图像。
- 变化对象：区间 `[a, x]` 上的阴影面积（`Integral(f, a, x)`，数值式即返回面积）、累积点 `(x, Φ(x))`、累积曲线。
- 观察重点：上限 x 增大时阴影面积累积、累积曲线的斜率恰为 f(x)。

要点（真机实测，T7）：

- 累积曲线**不能**用 `Integral` 直接作函数（反导数 `Integral(f,x)` 求值为 NaN、变限 `Integral(f,a,x)` 不创建，见 [anti-patterns.md](anti-patterns.md) A14）——改用**黎曼和**：`Phi(x) = Sum(f(a + (x - a) * i / n) * (x - a) / n, i, 1, n)`（n ≈ 200），再 `Curve(t, Phi(t), t, a, b)`；
- 辅助函数 `Phi` 会被自动绘制 → `SetVisibleInView(Phi, 1, false)` 隐藏；
- 阴影面积用 `Integral(f, a, x)`（数值式，随滑块实时变化）。

常用命令：`Integral`, `Sum`, `Curve`, `Segment`, `Point`, `Text`, `Slider`, `InputBox`。

### 4.11 复变映射模式

适用：复函数 z²、Möbius 变换、保角映射、网格变换。

设计套路：

- **复数用字面量 `a + b*i`**（点是坐标，不是复数；坐标对的 `^2` 是内积）——见 [anti-patterns.md](anti-patterns.md) A20。
- 网格线变换：竖直线 x=k → `Curve(k^2 − t^2, 2*k*t, t, −a, a)`；水平线 y=k → `Curve(t^2 − k^2, 2*k*t, t, −a, a)`；整族用 `Sequence(...)`（列表会渲染）。
- 原网格线用**深色粗线**（浅灰会和背景网格混淆）。

常用命令：`Curve`、`Sequence`、`Line`、`ImplicitCurve`、`SetLineThickness`。（真机实测，T20 复变 z² 网格。）

### 4.12 离散分布与逼近模式

适用：二项/泊松分布、二项 → 泊松极限、抽样分布经验直方。

设计套路：

- **pmf 显式算**：`BinomialCoefficient(n,k)*p^k*(1−p)^(n−k)`、`λ^k*exp(−λ)/k!`（不要依赖 `BinomialDist(n,p,k)` / `Poisson(λ,k)`，本引擎不可用，见 A19）。
- 柱：`Sequence(Segment((k, 0), (k, pmf(k))), k, 0, n)`，`SetLineThickness` 加粗；对比曲线：`Polyline(Sequence((k, pmf2(k)), k, 0, m))`。
- 视图：`ZoomIn(0, 0, n, 峰值)` 定向。

常用命令：`BinomialCoefficient`、`Polyline`、`Segment`、`Sequence`、`exp`、`ZoomIn`。（真机实测，T22 泊松极限。）

### 4.13 约束极值（拉格朗日乘数）模式

适用：条件极值、拉格朗日乘数法、等值线与约束相切。

设计套路：

- 约束：`ImplicitCurve(g(x,y))`（如 `x^2 + y^2 − 1`），加粗突出。
- 目标等值线：`ImplicitCurve(f(x,y) − c)`，`c` 为滑块，拖动看等值线"扫过"约束曲线。
- 相切处即极值；用点对象标出极值点。

常用命令：`ImplicitCurve`、`Slider`、`Point`、`SetLineThickness`。（真机实测，T21。）

### 4.14 假设检验：两类错误模式

适用：α（弃真）、β（取伪）、功效 1−β、临界值与效应量的权衡。

设计套路：

- 两条正态密度：`h0(x)=Normal(0,1,x,false)`、`h1(x)=Normal(d,1,x,false)`；临界值竖线。
- 着色：α 尾 `Integral(h0, zc, 6)`；β 区 `Integral(h1, −6, zc)`（`Integral` 既画区域又给出面积值）。
- 动态：`d`、`zc` 双滑块，文本实时显示 α、β、功效。

常用命令：`Normal`、`Integral`、`Segment`、`Text`、`ZoomIn`。（真机实测，T24。）

### 4.15 极限邻域（ε-δ）模式

适用：函数极限、ε-δ 语言、连续性的动态演示。

设计套路：

- 两条"带"：水平 ε-带 `Polygon((-b, L−ε), (b, L−ε), (b, L+ε), (-b, L+ε))`；竖直 δ-带同理（`a` 为中心）。
- 交互：ε、δ 两个滑块；在 δ-带边界取点 `(δ, f(δ))` 观察是否落入 ε-带。
- 观察重点：δ 足够小时，曲线在 δ-带内的部分完全落在 ε-带内。

常用命令：`Polygon`、`Slider`、`Point`、`SetLineThickness`。（真机实测，T26。）

### 4.16 曲线性态联动（f / f′ / f″）模式

适用：单调性、极值、凹凸性、拐点、三图联动。

设计套路：

- 三条曲线同图：`f`、`d = Derivative(f)`、`dd = Derivative(f, 2)`。
- 用滑块 `x0` 放点、切线，文本显示 `f(x0), f′(x0), f″(x0)`。
- 观察重点：`f′` 变号 → 极值；`f″` 变号 → 拐点。
- 注意：三条曲线量级差异大时，`ZoomIn` 选定合适窗口。

常用命令：`Derivative`、`Tangent`、`Slider`、`Text`、`ZoomIn`。（真机实测，T27。）

### 4.17 二次型等值线与主轴模式

适用：二次型、主轴变换、正定/不定、矩阵特征结构。

设计套路：

- 等值线：`ImplicitCurve(Q(x,y) − c)`，`c` 为滑块，`Q` 为二次型。
- 主轴（特征方向）：对**对称**矩阵 2×2 手算——`tr=a11+a22`、`det=a11a22−a12²`、`λ=(tr±√(tr²−4det))/2`，方向 `(a12, λ−a11)`；对称矩阵判别式恒 ≥0，无复数问题。
- 观察重点：等值线（椭圆/双曲线）的对称轴 = 特征方向。

常用命令：`ImplicitCurve`、`Line`、`If`、`sqrt`、`Slider`。（真机实测，T28；配合 anti-patterns A11：不用 `Eigenvectors`。）

### 4.18 曲率圆与曲率半径模式

适用：曲率、密切圆、弧长、曲线弯曲程度。

设计套路：

- 基础曲线 `f`（或 `Curve`）；可移动点 `P=(t, f(t))`。
- 密切圆 `OsculatingCircle(P, f)`；曲率 `Curvature(P, f)`，半径 `R = 1/κ`。
- 观察重点：平缓处 R 大、弯曲处 R 小；圆与曲线在该点相切且同曲率。

常用命令：`OsculatingCircle`、`Curvature`、`Slider`、`Point`。（真机实测，T30。）

### 4.19 回归稳健性（异常值 / 杠杆点）模式

适用：相关与回归、异常值影响、杠杆点、相关≠因果。

设计套路：

- 基础点集用列表 `base`（点列表，会渲染）；异常点用**可拖动点** `P0`（两个滑块控坐标）。
- 数据 `pts = Append(base, P0)`；拟合线 `FitLine(pts)`；相关系数 `CorrelationCoefficient(pts)`。
- 观察重点：拖动异常点，回归线与 r 被明显拉偏。

常用命令：`Append`、`FitLine`、`CorrelationCoefficient`、`Slider`、`Point`。（真机实测，T31。）

### 4.20 中值定理模式（罗尔 / 拉格朗日）

适用：罗尔定理、拉格朗日中值定理、柯西中值定理。

设计套路：

- 端点 `A(a, f(a))`、`B(b, f(b))` 与弦 `Segment(A,B)`；动点 `P(c, f(c))` 与其切线 `Tangent(P, f)`。
- 判据：罗尔（f(a)=f(b)）时切线斜率 = 0；拉格朗日时切线斜率 = 弦斜率 `Slope(Line(A,B))`。
- 求"中值点"用 `Root(f′ − 弦斜率, a, b)`（**不要** `Element(Intersect(...))`，见 A10）。

常用命令：`Tangent`、`Slope`、`Root`、`Segment`、`Slider`。（真机实测，T32/T1。）

### 4.21 数值求根（牛顿 / 割线）模式

适用：牛顿法、割线法、二分法、Euler 法——一切**迭代**过程。

设计套路：

- `Iteration`/`IterationList` 在本引擎**不可用**（见 A23）→ **手写前几步**：`x1 = x0 − f(x0)/f′(x0)`，`x2 = x1 − f(x1)/f′(x1)` …
- 牛顿法每步画切线与到 x 轴的垂线；**割线法**每步画过相邻两点的割线：`x2 = x1 − f(x1)(x1−x0)/(f(x1)−f(x0))`。
- 初始猜测作滑块。
- 观察重点：切线 / 割线逐步逼近根。

常用命令：`Tangent`、`Line`、`Segment`、`Slider`、`Text`。（真机实测，T33/T45。）

### 4.22 最小二乘（残差平方和）模式

### 4.58 圆锥曲线离心率模式

### 4.63 抽样分布（rug 图）模式

### 4.89 奇异值分解（SVD）几何模式

适用：奇异值分解、矩阵的几何作用、正交对角化直观。

设计套路：

- 构造**已知 SVD** 的矩阵：`M = R(a)·diag(s1,s2)·R(b)`，四元素显式展开（避开 CAS 专属命令）：
  `a11 = s1·cos a·cos b − s2·sin a·sin b`，`a12 = −s1·cos a·sin b − s2·sin a·cos b`，`a21 = s1·sin a·cos b + s2·cos a·sin b`，`a22 = −s1·sin a·sin b + s2·cos a·cos b`。
- 单位圆 `Curve(cos t, sin t, t, 0, 2*pi)`；像曲线 `Curve(a11*cos t + a12*sin t, a21*cos t + a22*sin t, t, 0, 2*pi)` = 椭圆。
- 右奇异向量 = R(b) 的两列 `(cos b, sin b)`、`(−sin b, cos b)`；其像 = `s1·(cos a, sin a)`、`s2·(−sin a, cos a)`，即椭圆半轴。
- 观察重点：**半轴长 = 奇异值**，方向 = 左奇异向量。

常用命令：`Curve`、`Vector`、`Slider`、`cos`。（真机实测，T104。）

### 4.90 多元链式法则（依赖树）模式

适用：复合函数求导 / 全导数、链式法则、依赖图。

设计套路：

- `z = f(x,y)`、`x = x(t)`、`y = y(t)`；动点沿参数路径 `Curve(x(t), y(t), t, …)`。
- 用 `Segment` + `Text` 画依赖树：z 在上、x/y 居中、t 在下，边标 `dz/dx`、`dz/dy`、`dx/dt`、`dy/dt`。
- 数值核对：`chain = fx·dx/dt + fy·dy/dt` 与 `direct = zt'(t)`（对复合函数导数的**数值调用**）应相等。
- 观察重点：两条路径之和 = 全导数。
- **坑**：树节点**必须大写名**（小写名+坐标会被当作向量，见 A1）；`x(t)`、`y(t)` 辅助函数会被自动绘制，用 `SetVisibleInView(fn, 1, false)` 隐藏（A18）。

常用命令：`Curve`、`Segment`、`Text`、函数导数 `f'(x)`。（真机实测，T105。）

### 4.91 格林公式（环流 = 旋度积分）模式

适用：格林公式、第二型曲线积分、环流、通量。

设计套路：

- 向量场小箭头 `Sequence(Sequence(Segment((i,j),(i-0.35j, j+0.35i)), i,-3,3), j,-3,3)`（旋转场，旋度 = 2）。
- 闭曲线 `Curve(R*cos t, R*sin t, t, 0, 2*pi)`。
- 左端（环流）用**离散求和**：`Sum((P(x,y)·(−R sin u) + Q(x,y)·(R cos u))·du, k, 0, n-1)`；右端（旋度积分）= `curl·πR²`；两者应相等。
- 观察重点：∮(Pdx + Qdy) = ∬(Qx − Py) dA。

常用命令：`Sum`、`Sequence`、`Segment`、`Curve`。（真机实测，T106。）

### 4.92 Frenet 标架（T/N/B）模式

适用：空间曲线的活动标架、切向/法向/副法向、曲率。

设计套路：

- 螺旋线 `Curve(a*cos t, a*sin t, b*t, t, 0, 2*pi)`；`s = sqrt(a^2 + b^2)`。
- **手算解析式**（避开 CAS 专属命令）：`T = (−a sin t, a cos t, b)/s`、`N = (−cos t, −sin t, 0)`、`B = T×N = (b sin t, −b cos t, a)/s`。
- 向量 `Vector(P, (x(P)+Tx, y(P)+Ty, z(P)+Tz))`；`SetCaption(VecT,"T")` 后**必须** `ShowLabel(VecT,true)` 才显示（见 A29）。
- 观察重点：T/N/B 两两正交（可用 `Dot` 核验 ≈ 0），构成沿曲线的活动坐标系。

常用命令：`Curve`、`Vector`、`SetCaption`、`ShowLabel`、`sqrt`。（真机实测，T107。）

### 4.93 简谐振动相图（中心）模式

适用：二阶线性 ODE 的相平面、中心 / 闭轨、能量守恒。

设计套路：

- 系统 `x' = v`、`v' = −w^2·x`；`SolveODE(v', x', x0, v0, tEnd, step)`（**顺序 v′, x′**，见 4.86）。
- 不同初值 → **同心闭轨**（w = 1 为圆，w ≠ 1 为椭圆）。
- 观察重点：轨线闭合 ⟺ 平衡点为中心（能量 `E = 0.5v² + 0.5w²x²` 守恒）；与鞍点/结点（4.86）对比。
- 初值振幅要**互异**，否则同振幅的初值会画出重合的轨线。

常用命令：`SolveODE`、`Slider`。（真机实测，T108。）

### 4.94 切比雪夫多项式（极小极大）模式

适用：切比雪夫 / 正交多项式、最小最大逼近、等幅振荡。

设计套路：

- `Tn(x) = If(-1 <= x <= 1, cos(n*arccos(x)))`（`If` 限定义域，避免 |x|>1 时 NaN）；`n` 用整数步长滑块。
- 极值点 `Sequence((cos(k*pi/n), cos(k*pi)), k, 0, n)`，值在 ±1 交替。
- 参考线 `Line((-1.1,1),(1.1,1))`、`Line((-1.1,-1),(1.1,-1))`。
- 观察重点：`|Tn(x)| <= 1` 且等幅振荡（n+1 个极值），即**极小极大**性质。

常用命令：`cos`、`arccos`、`If`、`Sequence`、`Line`。（真机实测，T109。）

## 7. 代码输出规范（AI 生成 GeoGebra 指令时的铁律）

### 主动思考“哪些对象可以变化”

设计动态演示时，应先列出可变对象候选，再筛选核心交互项与可选探索项。不要只把用户点名的量做成滑块；应围绕“学生需要看到什么变化”补充可探索入口。

常见可变对象：

- 高等数学：函数表达式、函数参数、区间端点、动点位置、趋近步长、分割数、显示范围、误差阈值；
- 线性代数：矩阵元素、向量端点、基向量、网格密度、变换动画参数、是否显示原像/像；
- 概率统计：分布参数、样本量、重复次数、置信水平、随机种子、重抽样按钮；
- 通用显示：是否显示辅助线、斜率/面积/误差文本、轨迹、关键提示。

交互形式建议：表达式用 `InputBox`；连续数值用 `Slider`；几何位置用可拖动点；显示开关用 `CheckBox`；重置、重抽样、自动吸附等用按钮或脚本。

输出方案时，交互变量表可分为：

1. **核心交互项**：直接服务当前教学目标，默认加入；
2. **可选探索项**：增强二次创作与课堂追问，但可能增加界面复杂度。

### 其余命令规范见 SKILL.md

Slider 完整语法、标签显示/隐藏、`InputBox` 关联函数、`Text()` 换行等命令编写规范见 [SKILL.md 的「GeoGebra 指令编写规范」](../../SKILL.md)。
