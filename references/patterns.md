# GeoGebra 教学创作模式库（v1.6 整合版）

本文件把 v1.5.x 实跑期累积的 **166 条扁平「创作模式」**按**数学主题族**整合为 **13 族 + 1 张通用技法表**：

- 每族先给 **共用套路**（可复用的设计 recipe + 该族高频真机坑 A/B 编号），再用 **成员表**列出各具体模式——**保留原 `4.x` 编号与实测标号（T##）**，便于回查历史实现。
- 真机坑 / 验证行为见 [anti-patterns.md](anti-patterns.md)；交互增强（按钮 / 动画 / 重置 / 重抽）见 [interaction-patterns.md](interaction-patterns.md)。
- 设计质量与版面纪律见 [SKILL.md](../SKILL.md) 的「需求澄清指导原则」。

> 用法：接到主题 → 先定位到族 → 读该族「共用套路」→ 在成员表找最接近的一条 → 按需回查原始实现。

## 0. 总原则与通用技法

### 0.1 从「想让学生看到什么变化」开始
把教学意图先翻译成**可观察的变化**——几何位置变化、逼近过程变化、参数影响变化、结构保持/改变、随机稳定性变化；再设计交互变量与构造。

### 0.2 交互变量设计
- **滑块**承载「教师希望学生调节的量」：位置（点/参数）、增量（`h`/`dx`）、分割数（`n`）、形状（`a,b,r,θ`）、矩阵元、概率参数（`p,λ,μ,σ,n`）。核心 **1–4 个**最清晰。
- **可拖动点**承载几何直觉（曲线取点、区域移点、向量端点）。
- 分级：核心交互项（默认显示）vs 可选探索项（默认隐藏/折叠）；**核心控件 ≤5**。

### 0.3 对象构造顺序
参数/滑块 → 基础函数/曲线/矩阵/曲面 → 派生点/线/面/区域 → 辅助对象 → 动态文本 → 样式与显隐 → 验证（拖动关键变量看核心变化是否显著）。

### 0.4 通用绘图技法（跨域复用 · v1.6 归纳）
| 技法 | 配方 | 备注 |
|---|---|---|
| 向量场箭头网格 | `Sequence(Sequence(Segment((i,j),(i+Fx,j+Fy)), i,…), j,…)` | 二维两层嵌套 `Sequence` 可用 |
| 柱状 / 直方图 | `Sequence(Segment((k,0),(k,v(k))), k,…)`；折线 `Polyline(点列表)` | `BarChart`/`Histogram` **不产出图形**（A21/A22） |
| 点阵 / 离散集合 | `Sequence(Sequence(If(cond(i,j),(i,j)), i,…), j,…)` | false 分支可缺省；生成点阵可见 |
| 参数曲线 / 曲面 | `Curve(x(t),y(t),t,a,b)`；`Surface(u,v,f(u,v),u,..,v,..)` | `Curve` 上限用常数更稳 |
| **手写迭代**（无 `Iteration`） | `x1 = g(x0)`、`x2 = g(x1)` … 前几项 | `Iteration`/`IterationList` 不可用（A23） |
| 双求和（无嵌套 `Sum`） | 内层单独定义 `inner = Sum(…)`，外层乘析出因子 | 嵌套 `Sum` 失败（A30） |
| 隐藏辅助对象 | `SetVisibleInView(fn,1,false)`（2D）/`(fn,-1,false)`（3D）；`ShowLabel(obj,false)` | 辅助/中间函数会被自动绘制（A12/A18） |
| 定视图 | `ZoomIn(minx,miny,maxx,maxy)` | 3D 预览取景不可控（B15） |
| 取列表元素 | `Element(list,k)`；`x(pts)`/`y(pts)` 取坐标列表 | 下标运算均可用 |
| 随机数 | `Random()∈[0,1)`；`Sequence(Random(),i,1,N)` | 每次重算会重抽 |
| 命名铁律 | 点/向量用**大写**名或 `Point(...)`；内置命令首字母大写 | 小写名+坐标=向量（A1）；`Max/Min` 大写（A32） |

## 1. 极限 · 连续 · 逼近族
**共用套路**：固定「目标对象」（切线 / 真值 / 极限），用参数（`h`/`n`/阶数）控制「逼近对象」，动态文本同时显示「当前值 vs 目标值/误差」；ε 语言用带状区域（`Polygon`）或点列判定。
**高频坑**：参数区间须含趋近两侧（如 `h` 含正负）；变上限积分用黎曼和（A14）；`Element(Intersect(…))` 求值失败 → 用 `Root`（A10）。

| 原 | 模式 | 关键点 |
|---|---|---|
| 4.1 | 逼近型 | `Sequence`/`RectangleSum`/`UpperSum`/`LowerSum`/`Integral`/`Tangent`/`TaylorPolynomial`/`Limit` |
| 4.2 | 局部线性化 | `Tangent`/`Derivative`/`Plane`/`Surface`；局部越小近似越好 |
| 4.10 | 变上限积分 | 累积曲线用黎曼和 `Sum(f(a+(x-a)i/n)(x-a)/n,i,1,n)`；阴影用 `Integral(f,a,x)`（数值式）（A14） |
| 4.15 | ε-δ 邻域 | ε-带 / δ-带 `Polygon` 嵌套；在带边界取点判定落入 |
| 4.30 | 夹逼定理 | 两条夹曲线 `±x²` 夹 `x²sin(1/x)` |
| 4.32 | 弧长折线逼近 | 折线长 `Sum(Length(段),…)` vs `Length(f,a,b)` |
| 4.33 | 函数列一致收敛 | `Sequence(x^k,k,1,n)`（列表元素为函数时会分别绘制）；极限函数用 `If` |
| 4.34 | 幂级数部分和 | `Sum(x^k,k,0,n)` 逼近 `1/(1−x)` |
| 4.35 | Weierstrass 分形 | `Sum(a^k·cos(b^k·π·x),k,0,n)`；处处连续处处不可导 |
| 4.36 | 洛必达法则 | 文本对比 `f(x0)/g(x0)` 与 `f′(x0)/g′(x0)` |
| 4.46 | 数列 ε–N | 阈值 `ceil(1/ε)`；点列 + ε 带 |
| 4.52 | 单调有界收敛 | 递推**手写**前几项；点列 `Polyline` + 极限 `Line`（A23/A25） |
| 4.62 | 闭区间套 | `Sequence(Segment((0,k),(1/k,k)),k,1,n)` |

## 2. 导数 · 函数性态族
**共用套路**：目标函数 `f` 与导函数 `f′`/`f″` 同图（导函数常需 `SetVisibleInView` 隐藏）；滑块放点、切线；动态文本给局部量。
**高频坑**：`Derivative(f,x)` 等中间函数会被自动绘制（A12/A18）。

| 原 | 模式 | 关键点 |
|---|---|---|
| 4.16 | f / f′ / f″ 联动 | `f′` 变号 → 极值；`f″` 变号 → 拐点 |
| 4.18 | 曲率圆与半径 | 2D：`OsculatingCircle(P,f)` + `Curvature`；**3D 曲线不可用**（A31） |
| 4.20 | 中值定理（罗尔/拉格朗日） | 切线斜率 = 弦斜率；中值点用 `Root(f′−弦斜率,a,b)`（A10） |
| 4.21 | 数值求根（牛顿/割线/二分） | 迭代**手写** `x1=x0−f/f′`…（A23） |
| 4.23 | 插值多项式与 Runge | `Polynomial(点列表)` 可用；`n` 大 → 端点振荡 |
| 4.41 | 可微但导数不连续 | `x²sin(1/x)`；`f′` 在 0 附近无限振荡 |
| 4.42 | 极值判别法 | `f′=0` 且 `f″` 定号 |
| 4.43 | 隐函数求导 | `Tangent(点,圆锥曲线)`；斜率解析式对照 |
| 4.44 | 反函数与镜像 | 反函数用参数曲线 `Curve(f(t),t,t,a,b)`；关于 `y=x` 对称 |
| 4.45 | 双曲函数 | `(cosh t, sinh t)` 在 `x²−y²=1` 上 |
| 4.54 | 悬链线 | `a·cosh(x/a)` vs 抛物线（形状接近但不同） |
| 4.57 | 渐近线 | 竖直/斜渐近线用 `Line` + `SetLineStyle(线,1)` |
| 4.73 | 复合函数 | 函数嵌套 `f(g(x))` 可用 |
| 4.76 | 幂指函数 xˣ | 对数求导；极小在 `x=1/e` |
| 4.80 | 图像变换 | `a·f(x−b)`；`a` 控纵向、`b` 控左右 |
| 4.81 | 反三角函数 | `atan`/`asin`/`acos` 主值区间 |
| 4.90 | 链式法则（依赖树） | 节点**大写名**（小写+坐标=向量，A1）；辅助函数 `x(t)`/`y(t)` 需隐藏（A18）；`zt'(t)` 数值调用可用 |

## 3. 积分 · 面积 · 体积族
**共用套路**：边界对象 + 代表微元（滑块控位置/尺寸）+「一个微元 → 累积整体」的文本对照；定积分 `Integral(f,a,b)`（数值端点）可用。
**高频坑**：为计算定义的辅助函数（如 `g=f²`）须 `SetVisibleInView` 隐藏（A18）。

| 原 | 模式 | 关键点 |
|---|---|---|
| 4.3 | 区域面积 / 体积 | `Integral`/`IntegralBetween`/`RectangleSum`/`Polygon`；从典型微元到整体 |
| 4.26 | 反常积分 | 上限 `R` 滑块；面积趋于有限（收敛）/持续增大（发散） |
| 4.37 | 数值积分（梯形/Simpson） | `h·Σ…` / `h/3·Σ…`；`Sequence(Polygon)` 画一排梯形 |
| 4.38 | 旋转体（圆盘法） | `V=π∫f²`；辅助函数隐藏（A18）；3D 可用 `Surface(f,2π)` |
| 4.70 | 二重积分区域 | 区域 `Polygon` + 条带 `Polygon` 扫过 |
| 4.79 | 曲顶柱体（3D） | 显式参数式 `Surface(u,v,f(u,v),u,a,b,v,c,d)` + 底面 `Polygon` |
| 4.83 | 雅可比行列式 | 小方块像面积 ≈ `|J|·du·dv` |
| 4.104 | 二重积分·极坐标累次 | `r³ dr dθ`；数值**可分离**（内层单层 `Sum` × `2π`，A30） |

## 4. 级数与展开族
**共用套路**：部分和 `Sum(项,k,0,n)`（`n` 为滑块）逼近目标；比较收敛性 / 误差界 / 正交性。
**高频坑**：`k!` 阶乘、`Sum` 上界为滑块均可用；`If` 限定义域避免 NaN。

| 原 | 模式 | 关键点 |
|---|---|---|
| 4.75 | 幂级数逐项求导 | `Sum(k·x^{k−1},…)` → `1/(1−x)²` |
| 4.94 | 切比雪夫多项式 | `cos(n·arccos x)`；`If(-1<=x<=1,…)` 限域；等幅振荡、极小极大 |
| 4.96 | 拉格朗日余项 | 误差 vs 上界 `e^x·|x|^{n+1}/(n+1)!`；定积分 `Integral(f,a,b)` 可用 |
| 4.97 | 勒让德多项式正交性 | 显式 P0..P4 + `If(m==n,…)` 选择；`Integral(Pm·Pn,−1,1)`；辅助乘积隐藏（A18） |
| 4.103 | 贝塞尔函数 | 级数定义；默认 `n≥2` 才看清「族」（n=0 与 J0 重合） |
| 4.106 | 傅里叶级数（锯齿波） | `2Σ(−1)^{k+1}sin(kx)/k`；端点 Gibbs 过冲 |
| 4.151 | 傅里叶级数（三角波） | `π/2−(4/π)Σcos((2k−1)x)/(2k−1)²`；连续函数 → 一致收敛、无 Gibbs |

## 5. 线性代数与矩阵族
**共用套路**：矩阵/向量由滑块控元；用「图形像」（`ApplyMatrix` 或显式展开）呈现矩阵作用；关键量手算。
**高频坑**：`Eigenvalues`/`Eigenvectors` 是 CAS 专属、导出引擎失败 → 2×2 手算（A11）；`Rank` 不可用（A26）；`Polygon` 带杂标签（A17）。

| 原 | 模式 | 关键点 |
|---|---|---|
| 4.5 | 变换型 | `Vector`/`ApplyMatrix`/`Translate`/`Rotate`/`Reflect`/`Dilate`；看结构保持/改变 |
| 4.9 | 手动特征分解（2×2） | `tr/det/disc` 手算，方向 `(a12, λ−a11)`；`If(disc>=0,…)` 防复数 |
| 4.17 | 二次型等值线与主轴 | 等值线 `ImplicitCurve(Q−c)`；对称矩阵判别式恒≥0 |
| 4.25 | 基变换与坐标 | 单位基下坐标 = `Dot(P,u)`/`Dot(P,v)`；`projU+projV=P` |
| 4.29 | 线性相关 / 共线判据 | `Determinant=0 ⟺ 相关`；`Rank` 不可用（A26） |
| 4.39 | 子空间与线性组合 | 组合 `(a·ux+b·wx, a·uy+b·wy)` 扫过平面 |
| 4.53 | 线性方程组几何形态 | 直线用 `ImplicitCurve(a·x+b·y−c)`（方程对象失败，A27）；`det` 判解个数 |
| 4.61 | 正交矩阵保长 | `Length(u)` 与 `Length(Ru)` 相等、`Angle` 不变 |
| 4.74 | 格拉姆-施密特 | `w⊥ = w − (⟨w,u⟩/⟨u,u⟩)·u`；`Dot(u,w⊥)=0` |
| 4.89 | 奇异值分解（SVD）几何 | 已知 SVD 展开 `M=R(a)diag(s1,s2)R(b)`；单位圆→椭圆，半轴=奇异值 |
| 4.95 | 约当块 | `J=[[λ,1],[0,λ]]` 剪切；迭代点手写；唯一特征方向 |
| 4.100 | 维数公式 | `Plane(三点)`+`Line`；`If(s==0,1,0)`；3D 文字预览不显示（B14） |
| 4.111 | 条件数与病态 | 近平行 `Line` + `Intersect(直线,直线)`；κ≈(2+ε)/ε；交点**大写名**（A1） |
| 4.117 | 幂法 | 归一化 `A^k`(单位圆) 像 → 收窄至主特征方向 |
| 4.120 | Gershgorin 圆盘 | 圆盘 `Circle((a_ii,0),Σ|a_ij|)`；`λ=(tr±√(Max(tr²−4det,0)))/2`（A11/A32） |
| 4.121 | PCA 主成分 | `x(pts)`/`y(pts)` + `Mean`/`Variance`/`Covariance`；2×2 特征分解；主轴+协方差椭圆 |
| 4.128 | 正定二次型曲面（3D） | `Surface(u,v,a·u²+2b·uv+c·v²,…)`；λ 符号定碗/鞍/槽 |
| 4.136 | 低秩逼近（SVD 截断） | rank-1 `s1·u1·v1ᵀ` 把单位圆压成线段 |
| 4.143 | QR 分解 | `q1=a1/|a1|`、`q2=(a2−r12q1)/|…|`；R 上三角 |
| 4.157 | Cholesky 分解 | `A=LLᵀ`：`l11=√a11,l21=a21/l11,l22=√(Max(a22−l21²,0))`；两步 `ApplyMatrix` |
| 4.161 | LU 分解（Doolittle） | `L={{1,0},{c/a,1}}`、`U={{a,b},{0,d−cb/a}}`；先 U 后 L |

## 6. 复变函数族
**共用套路**：复数用**字面量** `a+b·i`；曲线族显式映射后用 `Curve`/`Sequence` 画；原像用醒目色。
**高频坑**：坐标对 `(x,y)` 的 `^2` 是内积（A20）；原像别用浅灰（被网格吞）；`Beta` 无命令（A34）。

| 原 | 模式 | 关键点 |
|---|---|---|
| 4.11 | 复变映射（z² 网格） | 竖线 `Curve(k²−t²,2kt,…)`、横线 `Curve(t²−k²,2kt,…)`，整族 `Sequence` |
| 4.71 | 复变映射 / 反演 w=1/z | 不过原点的直线 ↔ 过原点的圆（保角） |
| 4.77 | 复数几何运算 | 字面量；`Vector((0,0),z)`；`|z1·z2|=|z1||z2|` |
| 4.78 | 单位根 / 正多边形 | `Sequence((cos(2πk/n),sin(2πk/n)),k,0,n−1)` + `Polygon` |
| 4.84 | 保角映射 | 像的方向**必须用导数** `d→f′(z₀)·d`，不能用有限弦（差 10°+） |
| 4.88 | 复数极坐标形式 | 模 `Distance((0,0),z)`、辐角 `atan2(y(z),x(z))` |
| 4.98 | 分式线性变换（圆→上半平面） | 实虚部显式公式 `Re=2y/D`、`Im=(1−x²−y²)/D`；辅助 `D(t)` 隐藏 |
| 4.102 | 欧拉公式 e^{iθ} | `cos/sin` 泰勒级数部分和（点）→ 单位圆点；辅助函数隐藏（A18） |
| 4.108 | 留数定理 | `Circle` 回路 + `If(R>1,2π,0)` 判包围极点；极点**大写名**（A1） |
| 4.160 | 共形映射（上半平面→带形） | `w=ln z`：射线→水平线 `Im=θ`、圆→竖直线 `Re=ln r`；只画像域网格 |

## 7. 常微分方程 · 动力系统 · 相图族
**共用套路**：`SolveODE` 数值式（**顺序 y′, x′**）画积分曲线 / 相轨；多初值得曲线族；参数滑块。
**高频坑**：二参 `SolveODE(f,点)` 返回不可求值 function（A15）；二阶/方程组用参数多的形式；无 `Iteration`（A23）。

| 原 | 模式 | 关键点 |
|---|---|---|
| 4.8 | 方向场与积分曲线 | `SlopeField(f,n)` + `SolveODE(f,x0,y0,xEnd,step)`；曲线族 `Sequence(SolveODE(f,0,0.2i,6,0.05),i,1,7)` |
| 4.27 | 数值解 ODE（Euler） | `Iteration` 不可用 → 手写 `y1=y0+h·f(x0,y0)`；`Polyline` 连折线 |
| 4.67 | 二阶线性 ODE（阻尼振动） | `SolveODE(b,c,f,x0,y0,y0',xEnd,step)`；ζ<1/=1/>1 三情形 |
| 4.68 | 一阶方程组 / 相平面 | `SolveODE(pred,prey,x0,y0,tEnd,step)`（顺序 y′,x′）；闭轨围绕平衡点 |
| 4.86 | 相图分类（鞍点/结点/焦点） | 线性系统 `SolveODE(y′,x′,…)` 多初值；类型由特征值决定 |
| 4.93 | 简谐振动相图（中心） | `x'=v, v'=−w²x`；同心闭轨；初值振幅要互异 |
| 4.99 | 焦点相图（稳定/不稳定） | `x'=μx−y, y'=x+μy`；特征值 μ±i；μ<0 螺旋收敛 |
| 4.105 | 结点相图 | `x'=ax, y'=by`；同号结点（符号定稳定）、异号鞍点 |
| 4.135 | RK4 与 Euler 精度对比 | 同 h 下手写 Euler 与 RK4(k1..k4)；`Polyline` + 精确解 |
| 4.137 | Logistic 映射蛛网 | `Polyline((x0,0),(x0,x1),(x1,x1),…)`；r>3.57 混沌 |
| 4.141 | 矩阵指数 e^{At} | `Curve(e^{σt}cos ωt, e^{σt}sin ωt,…)` 对数螺旋；σ 定收敛/发散 |
| 4.148 | SIR 传染病（相平面） | `SolveODE(dI/dt,dS/dt,S0,I0,…)`；峰值在 `S=γ/β`；R0=β/γ |
| 4.159 | Arnold 猫映射 | `(x,y)→((x+y)mod1,(x+2y)mod1)`；`M^k` 用 Fibonacci/Binet；`Mod` 大写（A32） |
